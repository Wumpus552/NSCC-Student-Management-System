# NSCC Student Management System

A web-based Student Management System prototype designed to demonstrate how students, instructors, and administrators could manage academic information through one centralized platform.

---

## Project Overview

The Nova Scotia Community College (NSCC) Student Management System project was created to address issues with outdated and disconnected tools used to manage student and course information.

The goal is to create a more centralized and user-friendly system that improves access to academic information, simplifies administrative tasks, and makes it easier for students and staff to manage their responsibilities.

This project currently focuses on the UI/UX design and front-end functionality of the proposed system.

---

## Features

The prototype includes three different user roles, each with its own dashboard and navigation options.

### Student Portal
- Student dashboard with an academic overview.
- View currently enrolled courses.
- Course registration interface.
- View grades and academic results.
- View attendance records.
- Access student profile information.
- View notifications and updates.

### Instructor Portal
- Instructor dashboard with a teaching overview.
- View assigned classes.
- Access student lists.
- View attendance information.
- Manage student grades.
- View and manage announcements.

### Administrator Portal
- Administrator dashboard with system statistics.
- Manage student accounts.
- Manage instructor accounts.
- Manage courses.
- Access academic records.
- View system reports.
- Access system settings.

## Getting Started

### Requirements

- A modern web browser (Chrome, Firefox, Edge, etc.).
- A code editor such as Visual Studio Code (optional).

No additional frameworks, packages, or installations are required.

### Running the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Select a user role from the login screen.
5. Enter a username and password.
6. Click **Login** to access the selected dashboard.

You can use any non-empty username and password to access the prototype.

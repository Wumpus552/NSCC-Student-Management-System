# NSCC-Student-Management-System
Project Management UI/UX Design Prototype

NSCC currently uses outdated tools to manage student and course information. This fragmented approach has created issues with slow administrative processes and inconsistent data. Faculty have reported challenges tracking attendance and academic progress. 

Due to this, the college leadership has requested a new centralized and modern Student Management System. This project was initiated to improve operational efficiency, reduce errors, and modernize the software that the college is using.
